# 담당부서 연락처 및 에스컬레이션 정책

> **데모용 가정 안내:** 아래 담당자와 연락처는 해커톤 데모용 가상 정보이며, 실제 담당자 또는 실제 회사 연락처가 아닙니다.

## 문의 유형별 담당 부서

| 문의 유형 | 담당 부서 | 담당자 |
|---|---|---|
| 입사 서류, 교육, 건강검진, 연말정산 | 인사팀 | 홍길동 대리 |
| 비품 신청, 전자결재 | 경영지원팀 | 인사팀을 통해 연결 |
| 계정·장비, 사내 시스템 오류 | IT팀 | 인사팀을 통해 연결 |
| 부서 합류 절차, 부서 업무 | 소속 부서 | 부서 리더 |

기본 문의처는 인사팀이며, 인사팀이 해당 부서로 연결합니다.

## 데모용 연락처

- 담당 부서: 인사팀
- 담당자: 홍길동 대리
- 이메일: `hr-demo@example.com`

이 연락처는 데모용 가상 정보입니다.

## 에스컬레이션 기준

챗봇은 아래 상황에서 답변을 확정하지 않고 담당 부서로 안내합니다.

- 확인 가능한 문서 근거가 충분하지 않은 경우
- 참고 문서 간 안내가 서로 다른 경우
- 개인별 예외 판단이 필요한 경우
- 문서의 유효기간이 지났거나 최신 여부가 불명확한 경우
- 개인의 세무·건강·법률 판단이 필요한 경우

## 표준 안내 문구

근거가 부족하거나 개별 판단이 필요한 경우 아래 문구로 안내합니다.

> 확인 가능한 문서 근거가 충분하지 않습니다. 인사팀 홍길동 대리(`hr-demo@example.com`)에게 확인해 주세요. 본 연락처는 해커톤 데모용 가상 정보입니다.

## 주의 사항

- 챗봇은 권한 부여, 실제 신청·결재 실행, 정책 예외의 최종 결정을 하지 않습니다.
- 문의 시 주민등록번호, 계좌번호, 비밀번호, 건강검진 결과를 메일 본문에 적지 않습니다.
- 타인의 인사 정보나 평가 정보에 대한 문의는 담당 부서에서 별도 절차로 처리합니다.
