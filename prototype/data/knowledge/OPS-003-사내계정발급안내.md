# 사내 계정 발급 안내 (데모 가정)

> **데모용 가정 안내:** 이 문서의 계정 종류와 절차는 해커톤 데모를 위한 가정이며, 실제 회사의 시스템 구성이나 IT 정책이 아닙니다. 실제 계정 발급 기준은 IT팀에 확인해야 합니다.

## 발급되는 계정

입사가 확정되면 아래 계정이 함께 생성됩니다. 별도로 신청하지 않아도 됩니다.

| 계정 | 용도 | 발급 시점 |
|---|---|---|
| 통합 계정 (사번) | 사내 포털·전자결재·그룹웨어 로그인 | 입사 첫날 오전 |
| 사내 메일 | 업무 메일 송수신 | 입사 첫날 오전 |
| 근태 시스템 | 출퇴근 기록, 휴가 신청 | 입사 첫날 |
| 부서 전용 시스템 | 소속 부서 업무 도구 | 부서 배치 후 |

사내 시스템은 **통합 계정 하나로 로그인**합니다. 시스템마다 별도 아이디를 만들지 않습니다.

## 첫 로그인 순서

1. 입사 첫날 사내 메일로 발송된 안내에서 **사번과 초기 비밀번호**를 확인합니다.
2. 사내 포털에 접속해 사번과 초기 비밀번호로 로그인합니다.
3. 첫 로그인 시 비밀번호 변경 화면이 표시됩니다. 새 비밀번호로 변경합니다.
4. 변경 후 다른 사내 시스템에도 같은 계정으로 접속할 수 있습니다.

초기 비밀번호는 첫 로그인 후 사용할 수 없습니다.

## 비밀번호 재설정과 재발급

비밀번호를 잊었을 때는 아래 순서로 **본인이 직접 재설정**합니다. IT팀에 요청하지 않아도 됩니다.

1. 사내 포털 로그인 화면에서 `비밀번호를 잊으셨나요?`를 선택합니다.
2. 사번과 사내 메일 주소를 입력합니다.
3. 사내 메일로 발송된 재설정 링크를 엽니다. 링크는 **30분간** 유효합니다.
4. 새 비밀번호를 입력하면 즉시 적용됩니다.

재설정 링크가 오지 않으면 스팸함을 먼저 확인합니다. 그래도 없으면 IT팀에 문의합니다.

**계정이 잠긴 상태에서는 재설정을 할 수 없습니다.** 비밀번호를 5회 연속 잘못 입력해 계정이 잠겼다면, IT팀에 잠금 해제를 먼저 요청한 뒤 재설정합니다.

사내 메일에 접근할 수 없는 경우에는 IT팀에 **임시 비밀번호 발급**을 요청합니다. 임시 비밀번호는 첫 로그인 시 반드시 변경합니다.

새 비밀번호는 챗봇을 포함한 어떤 시스템에도 입력해 알려주지 않습니다.

## 비밀번호 변경 주기와 화면 자동 잠금

- 비밀번호는 **90일마다** 변경합니다. 만료 14일 전부터 안내가 표시됩니다.
- 최근에 사용한 비밀번호는 다시 사용할 수 없습니다.
- 사내 시스템은 **10분 이상 조작이 없으면 화면이 자동으로 잠깁니다.** 잠금 해제에는 비밀번호를 다시 입력합니다.
- 자리를 비울 때는 자동 잠금을 기다리지 말고 직접 화면을 잠급니다.
- 비밀번호를 5회 연속 잘못 입력하면 계정이 잠깁니다. 잠금 해제는 IT팀에 요청합니다.

## 계정 문제 처리

| 상황 | 처리 |
|---|---|
| 비밀번호를 잊은 경우 | 로그인 화면에서 본인이 직접 재설정합니다 (위 재설정 절 참고) |
| 계정이 잠긴 경우 | IT팀에 잠금 해제를 요청합니다. 잠긴 동안에는 재설정할 수 없습니다 |
| 사내 메일에 접근할 수 없는 경우 | IT팀에 임시 비밀번호 발급을 요청합니다 |
| 첫날에 계정 안내를 받지 못한 경우 | 인사팀에 입사 처리 상태를 먼저 확인합니다 |
| 부서 이동으로 권한이 바뀐 경우 | 부서 리더가 변경을 요청하면 반영됩니다 |

## 노트북·장비 지급

- 업무용 노트북은 입사 첫날 IT팀에서 받습니다. 수령 장소는 IT팀입니다.
- 수령 시 자산 번호를 확인하고 인수 확인서에 서명합니다.
- 추가 장비(모니터, 키보드 등)는 비품 신청 절차를 따릅니다.
- 개인 장비를 업무에 사용하려면 사전 승인이 필요합니다.

## 퇴사·휴직 시

- 퇴사일에 모든 계정이 비활성화되고 장비를 반납합니다.
- 휴직 기간에는 계정이 일시 정지되며 복직 시 재활성화됩니다.
- 계정 비활성화 이후에는 사내 문서에 접근할 수 없습니다.

## 자주 묻는 질문

**사내 계정은 언제 발급되나요?**
입사 첫날 오전에 통합 계정과 사내 메일이 함께 생성되며, 별도 신청은 필요하지 않습니다.

**시스템마다 아이디를 따로 만들어야 하나요?**
사내 시스템은 통합 계정 하나로 로그인합니다. 시스템별 아이디를 따로 만들지 않습니다.

**비밀번호를 잊어버렸는데 어떻게 하나요?**
사내 포털 로그인 화면에서 `비밀번호를 잊으셨나요?`를 선택하고, 사번과 사내 메일로 본인 확인 후 메일로 받은 재설정 링크에서 새 비밀번호를 입력합니다. 링크는 30분간 유효합니다.

**비밀번호 재발급은 IT팀에 요청해야 하나요?**
본인이 직접 재설정할 수 있으므로 요청하지 않아도 됩니다. 다만 계정이 잠겼거나 사내 메일에 접근할 수 없을 때는 IT팀에 요청합니다.

**계정이 잠겼는데 어떻게 푸나요?**
잠긴 상태에서는 본인 재설정이 되지 않습니다. IT팀에 잠금 해제를 요청한 뒤 비밀번호를 재설정합니다.

**화면이 자꾸 잠기는데 왜 그런가요?**
10분 이상 조작이 없으면 화면이 자동으로 잠기는 설정입니다. 잠금 해제에는 비밀번호를 다시 입력합니다.

**업무용 노트북은 어디서 받나요?**
입사 첫날 IT팀에서 받습니다. 수령할 때 자산 번호를 확인하고 인수 확인서에 서명합니다.

**모니터나 키보드도 같이 받나요?**
노트북 외 추가 장비는 비품 신청 절차를 따릅니다.
