# 전자결재 기본 가이드

## 문서 작성

1. 사내 포털에 로그인합니다.
2. `전자결재` → `새 문서 작성` 메뉴를 선택합니다.
3. 문서 양식을 선택합니다. 양식이 정해져 있지 않으면 일반 기안 양식을 사용합니다.
4. 제목, 본문, 첨부 파일을 입력합니다.
5. 결재선을 지정한 뒤 상신합니다.

제목은 문서 내용을 알 수 있도록 구체적으로 작성합니다.

## 결재선 지정

| 구분 | 역할 |
|---|---|
| 기안자 | 문서를 작성하고 상신하는 사람 |
| 검토자 | 내용을 확인하고 의견을 남기는 사람. 생략할 수 있습니다 |
| 결재자 | 최종 승인 권한을 가진 사람. 최소 1명을 지정합니다 |
| 참조자 | 결재 결과를 공유받는 사람. 승인 권한은 없습니다 |

결재선은 부서와 문서 종류에 따라 달라집니다. 부서별 기본 결재선이 설정되어 있는 경우 자동으로 지정됩니다.

## 문서 상태

| 상태 | 의미 |
|---|---|
| 임시저장 | 작성 중이며 아직 상신하지 않은 상태 |
| 진행중 | 결재선의 승인을 기다리는 상태 |
| 승인 | 모든 결재자가 승인한 상태 |
| 반려 | 결재자가 반려한 상태 |
| 회수 | 기안자가 상신을 취소한 상태 |

## 반려 처리

결재자가 반려하면 기안자에게 알림이 전달됩니다.

1. 반려된 문서는 `내 문서` → `반려함`에서 확인합니다.
2. 반려 사유를 확인합니다.
3. 내용을 수정한 뒤 다시 상신합니다.

반려된 문서는 새로 작성하지 않고 기존 문서를 수정하여 재상신합니다. 그래야 문서 이력이 이어집니다.

## 회수

상신한 문서는 첫 결재자가 승인하기 전까지 회수할 수 있습니다. 승인이 시작된 뒤에는 회수할 수 없으므로 결재자에게 반려를 요청합니다.

## 주의 사항

- 첨부 파일에 개인정보나 대외비 자료가 포함되지 않았는지 확인합니다.
- 결재선을 잘못 지정하면 처리가 지연될 수 있으므로 상신 전에 확인합니다.
- 결재 권한은 직책과 부서에 따라 다르므로, 권한이 없는 사람을 결재자로 지정하면 상신되지 않습니다.

## 자주 묻는 질문

**전자결재 문서가 반려되면 어떻게 하나요?**
반려함에서 반려 사유를 확인하고, 내용을 수정하여 기존 문서를 다시 상신합니다.

**결재선을 잘못 지정했는데 수정할 수 있나요?**
첫 결재자가 승인하기 전이라면 회수한 뒤 결재선을 수정하여 다시 상신할 수 있습니다.
